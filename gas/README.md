# ตั้งค่า Backend (Google Sheets + Apps Script)

ทำครั้งเดียว ใช้เวลาประมาณ 10 นาที · ทุกอย่างฟรี ไม่ต้องผูกบัตร

---

## 1. สร้าง Google Sheet

1. เปิด [sheets.new](https://sheets.new) → ตั้งชื่อไฟล์ เช่น `ผังที่นั่งงานแต่ง`
2. ดู URL บนแถบที่อยู่ จะเป็นแบบนี้
   ```
   https://docs.google.com/spreadsheets/d/1AbCdEfGhIjKlMnOpQrStUvWxYz1234567890/edit
                                          └────────── นี่คือ SHEET_ID ──────────┘
   ```
3. **ก๊อป SHEET_ID เก็บไว้** — จะใช้ในข้อ 3

> ไม่ต้องสร้างชีตย่อยหรือหัวตารางเอง — สคริปต์สร้างให้ทั้งหมดในข้อ 4

---

## 2. สร้าง Apps Script

1. ในไฟล์ Sheet นั้น → เมนู **ส่วนขยาย (Extensions)** → **Apps Script**
2. ลบโค้ดตัวอย่าง `function myFunction() {}` ทิ้งให้หมด
3. เปิดไฟล์ [`Code.gs`](Code.gs) ในโปรเจกต์นี้ → ก๊อปทั้งไฟล์ → วางแทน
4. กด 💾 บันทึก (Ctrl+S)

---

## 3. ตั้งค่าลับใน Script Properties

> ⚠️ **ห้ามพิมพ์รหัสลงในไฟล์โค้ดเด็ดขาด** — repo นี้อาจเป็น public
> และ URL ของ Apps Script ที่ฝังอยู่ในหน้าเว็บ ใครก็อ่านได้
> รหัสที่อยู่ในโค้ดหรือในหน้าเว็บ = รหัสที่รั่วแล้ว

ในหน้า Apps Script → ไอคอน ⚙️ **การตั้งค่าโปรเจกต์ (Project Settings)**
→ เลื่อนลงล่างสุด → **คุณสมบัติสคริปต์ (Script Properties)** → **เพิ่มคุณสมบัติสคริปต์**

| ชื่อ (Property) | ค่า (Value) | ใช้ทำอะไร |
|---|---|---|
| `SHEET_ID` | ค่าที่ก๊อปจากข้อ 1 | บอกสคริปต์ว่าจะเขียนลงไฟล์ไหน |
| `ADMIN_PIN` | รหัสของเจ้าภาพ **อย่างน้อย 8 ตัว** | เพิ่ม/แก้/ลบรายชื่อได้ทุกอย่าง |
| `STAFF_PIN` | รหัสของพนักงานต้อนรับ **คนละตัวกับด้านบน** | เช็คอินได้อย่างเดียว |

**ทำไมต้องแยก 2 รหัส:** วันงานจะมีคนถือ tablet เช็คอินอยู่หน้าฮอลล์
ถ้าเขาถือรหัสเดียวกับเจ้าภาพ เท่ากับเขาลบรายชื่อทั้งงานได้ — ซึ่งไม่ควร

กด **บันทึกคุณสมบัติสคริปต์**

---

## 4. สร้างชีตและกลุ่มโต๊ะตั้งต้น

1. กลับไปหน้าโค้ด (ไอคอน `<>` ด้านซ้าย)
2. ช่องดรอปดาวน์ข้างปุ่ม ▶ Run → เลือก **`setup`**
3. กด **▶ Run**
4. ครั้งแรกจะขออนุญาตเข้าถึง Google Sheets
   → **ตรวจสอบสิทธิ์** → เลือกบัญชี → **ขั้นสูง** → **ไปที่ … (ไม่ปลอดภัย)** → **อนุญาต**

   > หน้าจอ "ไม่ปลอดภัย" นี้เป็นเรื่องปกติ — Google ขึ้นแบบนี้กับทุกสคริปต์ที่ยังไม่ได้ส่งตรวจ
   > สคริปต์นี้เป็นของคุณเอง เข้าถึงได้แค่ไฟล์ Sheet ที่คุณระบุ

5. ดู **บันทึกการดำเนินการ (Execution log)** ควรขึ้น
   ```
   ✅ เพิ่มโต๊ะตั้งต้น 40 โต๊ะ
   ✅ setup เสร็จ — ชีตในไฟล์: Guests, Tables, Log
   ```

กลับไปดูที่ Sheet จะมี 3 แท็บใหม่:

| ชีต | เก็บอะไร |
|---|---|
| `Guests` | รายชื่อแขก + เลขโต๊ะ + เวลาเช็คอิน |
| `Tables` | ชื่อกลุ่มของโต๊ะ 1-40 (ใส่ตามแปลน VIVACE ให้แล้ว) |
| `Log` | ประวัติทุกการเพิ่ม/แก้/ลบ — **แขกที่ถูกลบยังอยู่ในนี้ กู้คืนได้** |

## 5. Deploy เป็น Web App

1. ปุ่ม **ทำให้ใช้งานได้ (Deploy)** มุมขวาบน → **การทำให้ใช้งานได้ใหม่ (New deployment)**
2. ไอคอน ⚙️ ข้างคำว่า "เลือกประเภท" → เลือก **เว็บแอป (Web app)**
3. ตั้งค่า

   | ช่อง | เลือก |
   |---|---|
   | คำอธิบาย | `wedding seating v1` |
   | ดำเนินการในชื่อ (Execute as) | **ฉัน (Me)** |
   | ผู้ที่มีสิทธิ์เข้าถึง (Who has access) | **ทุกคน (Anyone)** |

   > ต้องเป็น **ทุกคน** เพราะแขกที่เปิดเว็บไม่ได้ล็อกอิน Google
   > ความปลอดภัยมาจาก PIN ที่ตรวจฝั่งเซิร์ฟเวอร์ ไม่ใช่จากการล็อกสิทธิ์ตรงนี้

4. กด **ทำให้ใช้งานได้** → ก๊อป **URL ของเว็บแอป** ที่ได้ (ลงท้ายด้วย `/exec`)

---

## 6. ใส่ URL ลงในเว็บ

เปิด [`js/core.js`](../js/core.js) แก้บรรทัดบนสุด

```js
const CONFIG = {
  GAS_URL: 'https://script.google.com/macros/s/AKfycb.../exec',   // ← วางตรงนี้

  couple:  { groom: 'ชื่อเจ้าบ่าว', bride: 'ชื่อเจ้าสาว' },        // ← แก้ชื่อด้วย
  venue:   'VIVACE สาขาบางปู',
  weddingDate: '2026-09-20',                                      // ← วันงาน
```

เสร็จแล้วเปิด `index.html` ทดสอบได้เลย

---

## 7. ตรวจความพร้อมก่อนวันงาน

ในหน้า Apps Script → เลือก **`healthCheck`** → **▶ Run** → ดู Execution log

ตรวจให้ 5 อย่าง:
- ตั้ง `SHEET_ID` / `ADMIN_PIN` / `STAFF_PIN` ครบ และรหัสไม่ซ้ำกัน
- ไม่มีโต๊ะไหนคนล้นเกินจำนวนที่นั่ง
- ไม่มีแขกที่เลขโต๊ะผิด
- ไม่มีชื่อซ้ำจนแขกสับสน
- โต๊ะไหนยังไม่มีรายชื่อบ้าง

**แนะนำให้รันซ้ำ 1 วันก่อนงาน**

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| เว็บขึ้น "ยังไม่ได้ตั้งค่า GAS_URL" | ยังไม่ได้ทำข้อ 6 | ใส่ URL ใน `js/core.js` |
| ขึ้น "ยังไม่ได้ตั้ง ADMIN_PIN" | Script Properties ไม่ครบ | ทำข้อ 3 ใหม่ |
| ล็อกอินแล้วขึ้น "รหัสผ่านไม่ถูกต้อง" ทั้งที่พิมพ์ถูก | แก้โค้ดแล้วยังไม่ได้ deploy ใหม่ | ดูหัวข้อ "แก้โค้ดแล้วต้องทำอะไร" ด้านล่าง |
| แขกเปิดเว็บแล้วข้อมูลไม่อัปเดต | เซิร์ฟเวอร์ cache ไว้ 30 วินาที | รอสักครู่แล้วรีเฟรช |
| Excel เปิด CSV แล้วภาษาไทยเพี้ยน | — | ไฟล์ที่ export มี BOM แล้ว ถ้ายังเพี้ยนให้เปิดผ่าน Google Sheets แทน |

### แก้โค้ดแล้วต้องทำอะไร

Apps Script **ไม่ได้** อัปเดต Web App อัตโนมัติเมื่อกดบันทึก

> **Deploy → จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชัน: ใหม่ → ทำให้ใช้งานได้**

ทำแบบนี้ URL เดิมจะยังใช้ได้ ไม่ต้องไปแก้ `core.js` ใหม่
(ถ้ากด "การทำให้ใช้งานได้ใหม่" จะได้ URL ใหม่ ต้องไปแก้ `core.js` ตาม)

## กู้คืนแขกที่เผลอลบ

1. เปิดชีต `Log`
2. หาแถวที่คอลัมน์ `Action` = `delete` และชื่อตรงกับที่ต้องการ
3. อ่านค่า `FullName` / `Nickname` / `TableNo` จากแถวนั้น
4. เพิ่มกลับเข้าไปในหน้าแอดมินตามปกติ

> ชีต `Log` เป็น append-only — ไม่มีคำสั่งไหนในระบบลบแถวใน Log
> ประวัติทั้งหมดของงานนี้อยู่ครบในนั้น
